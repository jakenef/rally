# Research

What we found out, with sources. Add to these files instead of leaving findings in a chat.

- `open-source.md`: repos, models and datasets we can build on, and what to skip
- `competitors.md`: DUPR, PB Vision, Dinkmate, facility booking software
- `risks.md`: the biggest problems, ranked, with mitigations
- `play-styles.md`: should similar play styles play together? What we found and what Rally does about it
- `open-questions.md`: things we don't know yet, each with a default we build meanwhile

When you check something (a license, a repo's quality, an API), write the date and what you found.
